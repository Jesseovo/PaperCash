关于这份书单 +

书单来自 arXiv 近期预印本与 Crossref 近一年按主题检索的期刊元数据，每天北京时间 08:20 左右更新。筛选只作用于当前收录的论文。摘要保持来源原文；来源未提供摘要时会明确注明。

引用是基于现有元数据的草稿，使用前请核对。预印本尚未必经过同行评审；深入研究时仍应阅读原文。收藏只保存在当前浏览器，可导出 BibTeX。
